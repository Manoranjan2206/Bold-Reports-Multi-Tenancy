================================================================================
DEPLOYMENT OPTIONS
================================================================================

Option 1: PM2 (RECOMMENDED - Simplest)
  $ npm install -g pm2
  $ pm2 start server/server.js --name bold-reports
  $ pm2 startup && pm2 save
  
Option 2: Systemd (Linux Service)
  $ sudo cp systemd/bold-reports.service /etc/systemd/system/
  $ sudo systemctl enable bold-reports
  $ sudo systemctl start bold-reports

Option 3: Docker (Container)
  $ docker build -t bold-reports .
  $ docker run -p 3001:3001 --env-file .env bold-reports

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "Cannot find dist folder"
Fix: Run 'npm run build' to create it

Issue: "Port 3001 already in use"
Fix: lsof -i :3001; kill -9 <PID>

Issue: "dotenv not found"
Fix: npm install

Issue: ".env file not loading"
Fix: Make sure file exists and is in project root

Issue: "Express won't start"
Fix: Run 'npm run start:prod' directly to see errors

Issue: "No SSL certificate"
Fix: Use Let's Encrypt: sudo certbot certonly --nginx -d your-domain.com

Issue: "Report viewer not loading"
Fix: Check server logs: pm2 logs bold-reports
